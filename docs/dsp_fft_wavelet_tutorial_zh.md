# 图像信号频谱分析入门到实战（FFT / 小波 / 采样 / 窗口 / 滤波 / 数值陷阱）

> 配套代码：`dsp_spectrum_tutorial.py`

这份教程专门针对你提到的“容易掉坑”的问题，给出**概念 + 可运行示例 + 排错清单**。建议边看边跑代码：

```bash
python dsp_spectrum_tutorial.py
```

---

## 1. 先建立最小正确心智模型

1. **FFT 不是“频率检测器”，而是投影**：它把信号投影到一组离散复指数基上。只有当你的频率恰好落在 DFT 栅格点上时，能量才会集中在单个 bin。
2. **采样决定你能看到什么**：采样频率 `fs` 决定奈奎斯特频率 `fs/2`，超过的都会混叠。
3. **窗口是在解决“截断”问题**：你截取有限长度数据时默认乘以矩形窗，会引入频谱泄漏。
4. **滤波是频域乘法（时域卷积）**：低通/高通/带通本质是频域掩模或频响设计。
5. **图像频谱是二维版本**：同样有采样、泄漏、混叠、窗口和边界条件问题。

---

## 2. 采样与混叠（aliasing）

### 坑点
- 误以为“FFT峰值就是原始频率”。
- 实际上，若 `f > fs/2`，观测到的是折叠频率：

\[
 f_{alias} = \left|\left((f + fs/2) \bmod fs\right) - fs/2\right|
\]

### 代码实践
在 `dsp_spectrum_tutorial.py` 里：
- `alias_frequency(f_hz, fs)`：计算理论混叠频率。
- `run_all_demos()` 中用 `650 Hz` 在 `fs=1024 Hz` 下演示混叠。

### 排错建议
- 先打印 `fs`、`N`、`df=fs/N`。
- 对可疑峰值先做 alias 反推，再判断是否是真实频率。

---

## 3. 格点（bin）与频谱泄漏

### 坑点
- 你设了 `50.3 Hz`，但 FFT 栅格可能是 `1 Hz` 步进，结果能量分散到很多 bin。
- 常见误判：“系统有很多寄生频率”。其实可能只是泄漏。

### 代码实践
- `fft_spectrum_1d(..., window=None)`：矩形窗（泄漏更明显）。
- `fft_spectrum_1d(..., window="hann")`：Hann 窗（旁瓣明显降低）。

### 关键修正
- 用窗函数时要做幅值修正。示例中用了 `coherent_gain = mean(window)` 做归一化。

---

## 4. 混频（mixing）与下变频

### 坑点
- 混频后频谱会出现和频与差频，若不做低通，会看到“多出来的峰”。

### 代码实践
- `mix_down(x, fs, lo_hz)` 使用实数本振相乘。
- 在示例里把 `50 Hz + 120 Hz` 与 `100 Hz` 混频，频谱会出现 `|f-f_lo|` 与 `f+f_lo` 分量。

### 经验
- 要“只保留基带”，混频后必须接低通。

---

## 5. 低通 / 高通 / 带通 与高斯平滑

### 坑点
- 频域硬切（brick-wall）看起来干净，但会带来振铃（时域/空间域 Gibbs）。
- 图像处理中常误用过窄带宽导致边缘伪影。

### 代码实践
- `lowpass_mask`、`bandpass_mask` + `freq_filter_1d`：演示理想掩模滤波。
- `gaussian_kernel_2d` + `conv2_fft`：演示高斯平滑（更平滑的频响，伪影通常更可控）。

### 经验
- 真实工程优先平滑过渡频响（如高斯、Butterworth、窗函数 FIR），少用硬切。

---

## 6. 图像频谱可视化正确姿势

### 坑点
- 直接显示 `abs(FFT)`，动态范围太大，细节全黑。
- 忘记 `fftshift`，低频不在中心。

### 代码实践
- `fft_magnitude_image(img, log_scale=True)` 内部用了：
  1) `fft2`
  2) `fftshift`
  3) `log1p(abs(F))`

### 建议
- 总是看 `log` 频谱。
- 对比“滤波前后频谱中心/高频环带能量”。

---

## 7. 小波（Wavelet）怎么和 FFT 配合理解

### 直觉
- FFT：全局频率分解，频率分辨率高，但时间/空间定位弱。
- 小波：多尺度局部分析，适合突变、边缘、非平稳信号。

### 代码实践
- `haar_dwt_1level(x)`：手写 1 层 Haar 分解（近似分量 + 细节分量）。

### 什么时候用小波
- 你关心“哪里发生了突变”而不是“全局有哪些频率”时。

---

## 8. 数值发散与 artifacts 常见来源

1. **FFT 归一化不一致**：不同库默认规范不同，幅值比较要统一。
2. **DC 分量没去除**：低频抬升掩盖其他成分。
3. **边界条件错误**：循环卷积 vs 线性卷积混淆。
4. **零填充不足**：线性卷积用 FFT 时尺寸应 `N+M-1`。
5. **浮点精度与动态范围**：高动态范围图像建议 `float64` + `log` 显示。
6. **滤波器设计过陡**：导致空间域振铃。
7. **频域索引错位**：忘了 `fftshift` 或坐标尺度没换算。

---

## 9. 建议的“不会迷路”调试流程

1. 先用合成信号（已知频率和幅值）验证你的代码。
2. 检查采样参数（`fs, N, df, Nyquist`）。
3. 比较矩形窗 vs Hann 窗，确认泄漏行为符合预期。
4. 混频后必须检查和频/差频是否都存在。
5. 频域滤波后回到时域，确认波形是否出现不合理振铃。
6. 图像频谱必须 `fftshift + log1p` 再看。
7. 出现奇怪尖峰时，先排查混叠与索引错误，再怀疑算法。
